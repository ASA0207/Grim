# GRIM Guild Official 2026

테일즈런너 GRIM 길드 공식 GitHub Pages 프로젝트입니다.

## 배포
이 ZIP의 파일을 GitHub 저장소 루트에 그대로 업로드한 뒤 **Settings → Pages → Deploy from a branch → main / root** 를 선택하면 됩니다.

## BGM
- Stephen - Crossfire
- 파일: `assets/crossfire.mp3`
- GRIM 입장 버튼 또는 Enter 키로 사이트에 들어가면 재생됩니다.
- 우측 하단 플레이어에서 재생/일시정지 및 볼륨 조절이 가능합니다.
- 기본 볼륨은 28%이며 반복 재생됩니다.

음원 공개/배포 시에는 해당 음원에 대한 이용 권한과 GitHub 저장소 공개 범위를 직접 확인해주세요.
