# GRIM Guild Website 2026

테일즈런너 GRIM 길드 공식 모집 페이지입니다.

## GitHub Pages 배포
1. 이 폴더의 `index.html`, `style.css`, `script.js`를 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소 → Settings → Pages로 이동합니다.
3. Deploy from a branch → `main` / `/ (root)` → Save를 선택합니다.
